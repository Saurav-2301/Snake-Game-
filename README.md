# 🐍 Snake Game (HTML • CSS • JavaScript)

This is a simple and interactive **Snake Game** built using pure Frontend technologies (HTML, CSS, JavaScript). Use the arrow keys to control the snake and eat the food to increase your score. The game ends when you collide with the wall or with yourself.

---

## 🎮 Features
- Smooth snake movement with arrow keys
- Score increases as you eat food
- Random food generation on grid
- Game Over detection (wall or snake body collision)
- Responsive grid-based board
- Beginner-friendly JavaScript logic

---

## 🛠️ Tech Stack
| Technology | Purpose |
|------------|----------|
| HTML       | Game structure |
| CSS        | Styling + grid layout |
| JavaScript | Game logic & movement |
